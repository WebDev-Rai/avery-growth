# AA Styling — Growth Site

A responsive multi-page website ready for GitHub Pages. The publishable website is entirely inside `docs/`.

## Included pages

- Home
- Portfolio
- Services + Pricing
- First Visit
- About Avery
- Contact

## Publish on GitHub Pages

1. Create a new GitHub repository and upload this project.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select your default branch and the `/docs` folder, then save.

## Before launch

- Confirm Avery’s biography, services, pricing, policies, salon details, and schedule.
- Replace every sample booking link with the correct salon/Square URL.
- Create a Formspree form and replace `YOUR_FORM_ID` in `docs/contact.html`.
- If using the newsletter, replace `YOUR_MAILCHIMP_URL` in each page footer with Mailchimp’s embedded-form action URL.
- Connect the final domain and confirm image/testimonial permissions.

The contact and newsletter forms deliberately stay in preview mode until real endpoints are added.
